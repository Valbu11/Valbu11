## 🚀 Featured Project

### [🧠 Neurovault Brain Data Analysis](https://github.com/Valbu11/Neurovault-Brain-Data-Analysis)

End-to-end exploratory data analysis of **17,216 real brain imaging studies** from the NeuroVault public API.

**What I did:**
- Consumed a REST API and extracted 17,000+ neuroscience records with Python
- Cleaned and transformed data with Pandas (107 columns → 15 useful features)
- Analyzed patterns using SQL queries (GROUP BY, JOIN, CTEs)
- Created 5 professional visualizations with Matplotlib & Seaborn
- Discovered that brain imaging research grew +24,000% from 2013 to 2024
